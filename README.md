# 6. 기술 검증 및 실증

> **작성 상태:** 세부 내용 작성 완료
>
> **핵심 결론:** 본 사업의 검증은 정확도 수치를 먼저 주장하는 방식이 아니라, 안전한 Mock 환경에서 장치의 기계·영상·데이터 반복성을 확인한 뒤 전문기관의 기준검사 비교와 실제 농장 장기운영으로 확장하는 단계적 구조로 수행한다. 현재 제품인 1 Sampling Point / 1 Analysis Unit과 AI Early Warning Platform을 우선 검증하고, Multi-point Monitoring과 Epidemiological Risk Graph는 후속 가설로 분리한다.

본 시스템은 AIV를 확진하는 장비가 아니므로 자체 신속검사 결과만으로 성능을 확정하지 않는다. 최종 진단성능은 전문기관의 공식검사 또는 RT-qPCR 등 기준검사와 비교하여 평가하며, 실제 감염성 검체는 적절한 생물안전시설과 전문기관의 절차 안에서만 취급한다.

## 검증 근거수준과 공모전 이후 실행원칙

| 검증단계 | 공모전에서 확정하는 것 | 공모전 이후 확보할 증거 | 통과하지 못할 경우 |
|---|---|---|---|
| 기능검증 | 시험항목·기록구조·실패상태 | Mock 반복시험, 기계·영상·데이터 로그 | 설계·State Machine 수정 |
| 분석검증 | 비교원칙과 추적성 | 키트 IFU, 수동대비 자동검사, Lot·Matrix 결과 | 전처리·키트·사용목적 수정 |
| 전문기관 검증 | 기준검사 Pairing 구조 | RT-qPCR 등 기준검사 비교와 불일치 분석 | 성능주장 축소 또는 제품역할 변경 |
| 농장검증 | 운영 KPI와 안전중단조건 | 장기가동, Invalid, 작업시간, 유지관리 | 설치구조·SLA·대상농장 수정 |
| 공공검증 | 효과측정 인과경로 | 경보확인·공식검사 연결·사용평가 | 공공관제 기능·구매모델 수정 |

표본수와 합격수치를 근거 없이 공모전용 숫자로 만들지 않는다. Gate 0에서 키트 IFU, 예비시험, 전문기관 자문과 사용목적을 바탕으로 시험계획을 승인하고, 승인된 계획의 버전과 변경사유를 기록한다.

각 가설은 다음 공통 형식으로 관리한다.

> **가설 → 시험대상 → 비교대상 → 반복·표본설계 → 측정지표 → 잠정 통과기준 → 실패원인 → 수정·중단결정 → 책임자·근거문서**

## 6.1 핵심 검증 가설

> **Killer Hypothesis:** 설정된 Sampling Point에서 반복 확보한 분변 통합시료의 AIV 신속항원 신호가 기존 임상인지 또는 예정된 공식검사보다 의미 있는 선행정보를 만드는가?

공모전 본문에서는 다음 4개를 최우선 검증가설로 제시하고, 기존 가설 6~10은 오류통제·공식비교·후속확장의 하위 시험항목으로 관리한다.

| 우선순위 | 핵심 검증가설 | 주요 판정근거 |
|---:|---|---|
| 1 | Sampling 재현성·대표범위 | 반복편차, 지점·시간 비교, 누락·간섭 |
| 2 | 분변 Matrix–상용키트 적합성 | C선 유효성, Invalid, 기준검사 Pairing |
| 3 | 자동판독 반복성 | 기준판독 일치, T/C 반복편차, QC |
| 4 | 조기경보 가치 | 단일검사·임상인지·예정검사 대비 선행시간 |


### 가설 1. 반복 소량채취가 재현 가능한 Composite Sample을 만들 수 있는가

계분벨트의 설정된 Sampling Point에서 여러 시점에 소량을 반복 채취하고 하나의 Composite Cartridge에 통합하는 동작이 일정하게 수행되는지 확인한다.

주요 확인사항:

- Belt Run Signal 또는 Encoder 기반 Trigger 재현성
- Sampling Arm 진입·복귀 성공
- 정상적인 계분 배출 방해 여부
- Sampling Event 누락과 중복
- Composite Sample 생성 성공
- Sampling Point·Cycle·Event 기록의 추적성

현재 단계에서는 한 Sampling Point가 축사 전체를 대표한다고 가정하지 않는다. 먼저 해당 지점에서 반복 가능한 채취데이터를 생성할 수 있는지를 검증한다.

### 가설 2. 일회용 카트리지 기반 전처리가 반복 가능한 상층액을 만들 수 있는가

일회용 카트리지 안에서 분변과 완충액을 혼합하고 고형물을 침전시킨 뒤 상층액을 채취하는 과정이 반복 가능한지 확인한다.

주요 확인사항:

- 카트리지 장착과 밀폐상태
- 혼합동작과 시간의 반복성
- 침전 후 상층액 영역의 재현성
- 침전물을 과도하게 흡입하지 않는지 여부
- 상층액 채취와 분주동작의 성공률
- 검체접촉부와 다회용 본체의 분리

최적 시료량, 희석비, 혼합·침전시간과 상층액 흡입높이는 시험결과와 키트 IFU를 바탕으로 결정한다.

### 가설 3. 상용 AIV 신속항원키트를 자동으로 일관되게 취급할 수 있는가

사람이 수행하던 시료분주, 반응시간 관리, 촬영과 결과기록을 장치가 반복적으로 수행할 수 있는지 확인한다.

주요 확인사항:

- Cassette 장착감지
- Sample Well 위치에 대한 분주 반복성
- 검사 시작·판독시각 기록
- 제품별 반응시간 준수
- 검사 실패와 오류상태 기록
- Kit Type·Lot과 결과의 연결

키트별 사용조건은 제조사의 사용설명서와 전문기관 검증결과를 기준으로 한다.

### 가설 4. 고정 촬영환경에서 C선·T선을 재현성 있게 판독할 수 있는가

고정된 카메라·조명·거리·각도와 판독시간 조건에서 C선·T선의 정성 결과와 반정량 optical signal을 안정적으로 생성할 수 있는지 확인한다.

주요 확인사항:

- Cassette ROI 검출
- C선 탐지와 Invalid 구분
- T선 탐지
- 육안 또는 기준 판독과의 정성 일치도
- 반복촬영 C선·T선 신호와 T/C 변동
- 조명·위치·초점 변화에 대한 강건성
- Retake Required와 Uncertain 분류

T/C는 바이러스 절대농도가 아니라 정성판독을 보조하는 반정량 신호로 평가한다.

### 가설 5. 반복검사 시계열이 단일 검사보다 재검 우선순위 선별에 도움이 되는가

현재 결과만 사용하는 방식과 동일 Sampling Point의 변화추세를 함께 사용하는 방식을 비교한다.

비교대상:

- 현재 T/C 신호
- 직전 검사 대비 변화량
- 최근 N회 기울기
- 연속 상승
- 농장별 baseline 편차
- 자동 재검 결과
- 정성 결과와 QC

실증 전에는 조기탐지 시간이나 정확도 개선폭을 확정적으로 제시하지 않는다.

### 가설 6. 자동 재검이 일시적 오류와 반복 위험신호를 구분하는 데 도움이 되는가

약한 신호, Uncertain 또는 QC 문제가 발생했을 때 자동 재검을 수행하여 일회성 촬영·키트·분주 오류와 반복되는 생물학적 위험신호를 구분할 수 있는지 평가한다.

### 가설 7. Wet Zone과 Dry Zone 분리가 교차오염과 유지관리 부담을 줄일 수 있는가

검체접촉부를 일회용으로 두고 다회용 본체에 검체가 흐르지 않게 했을 때 시료 간 carry-over, 누액, 세척시간과 교체작업을 관리할 수 있는지 확인한다.

### 가설 8. 시스템 경보를 공식검사 결과와 비교할 수 있는가

전문기관 협력단계에서 시스템 경보시점, T/C 추세와 Risk Level을 공식검사 또는 RT-qPCR 결과와 연결한다.

확인사항:

- 정성 결과 일치도
- 위양성·위음성
- T/C와 기준검사 값의 관계
- 경보시점과 공식 확인시점
- 시스템 경보가 공식검사를 앞당길 가능성

### 후속가설 9. Multi-point Monitoring이 단일지점의 대표성 한계를 보완하는가

후속 단계에서 동일 축사 내 2~3개 Sampling Point를 독립 검사하여 단일지점 대비 공간적 검사정보가 증가하는지 평가한다.

각 지점의 원자료를 유지하며 시료를 먼저 혼합하지 않는다. 다지점 감시의 성능개선 폭은 비교실증 전까지 확정하지 않는다.

### 후속가설 10. Epidemiological Risk Graph가 확인·추적 우선순위 설정을 지원할 수 있는가

허가된 Mock 데이터, 협력농장 자체 데이터 또는 기관 제공데이터로 농장·차량·시설의 방문관계를 구성한다.

검사 위험신호와 이동관계를 결합했을 때 잠재적 연결농장 후보와 확인 우선순위를 생성할 수 있는지 평가한다. AI는 공식 역학관계를 확정하지 않으며 전문기관의 판단을 지원한다.

## 6.2 단계별 실증계획

### STEP 1. Analysis Unit 기능검증

실제 감염성 검체를 사용하지 않고 안전한 모사시료와 샘플 Cassette 이미지를 이용한다.

검증범위:

- 일회용 카트리지 장착
- 혼합과 침전시간 관리
- 상층액 위치제어
- 일회용 Tip 채취·분주
- Cassette Stage
- 반응시간 기록
- Camera 촬영과 결과저장

완료조건은 각 모듈이 State Machine에 따라 순서대로 동작하고 오류상태와 복구이력이 기록되는 것이다. 이 단계에서는 진단성능을 주장하지 않는다.

### STEP 2. 1 Sampling Point 통합검증

계분벨트 낙하부 모형을 제작하고 Sampling Unit과 Analysis Unit을 연결한다.

검증범위:

- 스크레이퍼 이후·Cross Conveyor 이전 위치 재현
- Belt Run Signal 또는 Encoder Trigger
- Swing Sampling Cup 진입·복귀
- 여러 Sampling Event 반복
- Composite Sample 생성
- Sampling Point·Cycle과 Test ID 연결
- End-to-End 자동검사

현재 MVP의 목표는 단일지점 자동화 연결을 검증하는 것이며 축사 전체 대표성을 입증하는 것이 아니다.

### STEP 3. 자동화·영상·데이터 반복성 검증

동일한 Mock 조건에서 전체 검사과정을 반복 수행한다.

검증범위:

- 채취·혼합·침전·분주·촬영 시간오차
- 장치 성공·실패율과 오류유형
- 반복촬영 C선·T선 신호와 T/C 변동
- C선 Invalid 검출
- 데이터 누락과 timestamp 순서
- 자동 재검 State Machine
- Rule-Based Risk와 Reason Code 재현성

조명, Cassette 위치, 초점, 시료상태와 통신상태를 의도적으로 변화시켜 QC와 오류처리의 강건성도 평가한다.

### STEP 4. 전문기관 공동검증

실제 분변 검체와 상용 AIV 신속항원키트의 적용성은 수의·바이오 전문가와 적절한 전문기관이 참여하는 조건에서 평가한다.

검증범위:

- 실제 분변의 채취·전처리 적용성
- 분변 수분·점도와 고형물 영향
- 키트별 사용조건과 자동화 호환성
- T/C 신호 반복성
- 기준검사와의 정성 일치도
- RT-qPCR 등 기준값과 T/C 관계
- 위양성·위음성
- 시료 간 교차오염

실제 감염성 AIV 검체는 프로젝트 팀이 임의로 취급하지 않는다.

### STEP 5. 소수 협력농가 실증

충북 내 협력 가능한 계분벨트식 산란계·종계 농장에서 정상시기의 장기 반복운영 데이터를 먼저 확보한다.

검증범위:

- 농장설비와 Sampling Unit 설치호환성
- 계분벨트 운전주기와 Trigger 안정성
- 농장별·Sampling Point별 baseline
- 분진·습도·온도·암모니아 등 환경영향
- 장비 가동률과 유지관리 빈도
- 오경보와 Invalid 발생양상
- 농장 관리자 개입시간과 수용성

위험신호가 발생한 경우 기존 방역절차에 따라 전문기관 확인검사로 연결하고, 경보와 공식 결과를 사후 비교한다.

### STEP 6. Multi-point·이동관계·공공연계 검증

기본 제품의 성능과 운영성이 확인된 이후 진행한다.

Multi-point 검증:

- 동일 축사 2~3개 지점의 독립검사
- 지점별 T/C와 Risk 변화
- 단일지점과 다지점 결과 비교
- 검사키트·유지관리 비용 증가
- 소프트웨어 Risk Integration

Movement Risk 검증:

- Farm·Vehicle·Facility·Visit 데이터 모델
- 방문순서와 시간간격
- Network Graph 시각화
- 연결농장 후보와 우선순위
- 전문기관 판단과의 사후 비교

공식 데이터 연계는 기관 협력, 제공권한과 법적근거가 확보된 경우에만 수행한다.

## 6.3 성능 평가방법

### 1. 평가 기본원칙

- 모든 시험은 Sampling Point, 장비·알고리즘 버전, Kit Type·Lot과 시간을 기록한다.
- 기능검증, 분석성능 검증, 현장운영 검증을 분리한다.
- Mock 결과를 실제 진단성능으로 표현하지 않는다.
- 동일 조건 반복시험과 조건변화 시험을 구분한다.
- 실패·Invalid·Uncertain 결과도 제외하지 않고 원인별로 기록한다.
- 기준값이 없는 단계에서는 반복성과 추적성을 우선 평가한다.
- 공식검사 label이 확보된 이후에만 진단성능 관련 지표를 계산한다.

### 2. 기계·Sampling 평가

평가항목:

- 예정된 Sampling Event 대비 실제 채취 성공률
- Sampling Arm 진입·복귀 성공률
- Composite Sample 생성 성공률
- Sampling Cycle별 시료량 또는 QC 변동
- 벨트 정상배출 방해와 장치 간섭
- Cartridge·Cassette 장착감지
- 누액·막힘·Actuator 오류

반복시험은 동일 조건에서 수행하고 농장구조, 벨트속도, 분변 수분상태와 Sampling Timing 변화에 따른 성능을 별도로 비교한다.

### 3. 전처리·분주 평가

평가항목:

- 혼합시간과 동작 반복성
- 침전 후 상층액 채취 성공률
- 침전물 혼입 또는 고형물 carry-over
- 분주 위치와 분주량 반복성
- 카트리지·Tip 교체 성공률
- 검체접촉부와 본체 사이 누액
- 시료 간 교차오염

정확한 허용오차는 장치 반복성 시험과 사용할 키트 조건을 바탕으로 결정한다.

### 4. 카메라 판독 평가

평가항목:

- Cassette ROI 탐지율
- C선 탐지와 Invalid 분류
- 정성판독 일치도
- 동일 Cassette 반복촬영 T/C 변동계수
- 조명·각도·위치·초점 변화 영향
- Retake Required와 Uncertain 검출
- 알고리즘 버전별 재현성

가능하면 사람이 라벨링한 판독결과 또는 전문기관 판독을 비교기준으로 사용한다.

### 5. AI Early Warning 평가

초기 Rule-Based 단계:

- 동일 입력에 대한 위험등급 재현성
- Reason Code와 권고조치의 일관성
- 자동 재검 Trigger와 완료율
- QC 오류와 생물학적 위험신호의 구분

공식검사 label 확보 이후:

- 민감도·특이도 후보
- 위양성률·위음성률
- Precision·Recall
- Risk Level calibration
- 단일 검사 대비 시계열 모델의 재검 우선순위 성능
- 경보와 공식 확인검사 사이의 선행시간

모델 개발·평가 데이터는 농장과 시간단위 누수를 방지하도록 분리한다. 복잡한 모델보다 설명가능성과 재현성을 우선한다.

### 6. 현장운영 평가

- 장비 가동률
- 검사 자동수행 성공률
- 관리자 개입시간
- 소모품 교체시간
- 장애복구시간
- 검사 1회당 소모품비
- 농장당 유지관리 빈도와 비용
- 통신두절 시 로컬검사와 재동기화
- 농장 관리자와 방역 담당자의 사용성

### 7. Epidemiological Risk Graph 평가

기관 협력 또는 허가된 데이터가 확보된 이후 평가한다.

- Farm·Vehicle·Visit 데이터 완전성
- Network Graph 생성 성공률
- 방문순서와 시간관계 재현
- 알려진 연결관계의 후보목록 포함 여부
- 상위 우선순위 후보의 적절성
- 위험농장 확인 후 우선순위 목록 생성시간
- 전문기관의 공식 역학조사 결과와 사후 비교

이 지표는 공식 역학판정의 대체성능이 아니라 조사 지원정보의 유용성을 평가한다.

## 6.4 핵심 성과지표(KPI)

아래 KPI는 평가항목 후보이며 수치목표는 아니다. 목표값은 시험설계, 키트 IFU, 전문기관 자문과 예비실험 이후 확정한다.

### 1. Sampling·기계 KPI

| KPI | 정의 |
|---|---|
| Sampling Event 성공률 | 예정된 Event 중 정상 채취·복귀가 완료된 비율 |
| Composite Sample 생성률 | Sampling Cycle 중 통합시료가 정상 생성된 비율 |
| Sampling 기록 완전성 | Point·Cycle·Event·시간정보가 모두 연결된 비율 |
| 시료량 반복성 | 동일 조건에서 Composite Sample 양의 변동 |
| 전처리 자동수행 성공률 | 혼합·침전·상층액 채취가 완료된 비율 |
| 자동분주 성공률 | Sample Well 위치에 정상 분주된 비율 |
| 장비 실패율 | 누액·막힘·센서·Actuator 오류가 발생한 검사 비율 |
| 안전복귀 성공률 | 오류 후 장치가 안전상태로 전환된 비율 |

### 2. 영상판독 KPI

| KPI | 정의 |
|---|---|
| Cassette ROI 탐지율 | 판독 가능한 이미지에서 Cassette 영역을 찾은 비율 |
| C선 탐지율 | 유효 Cassette의 C선을 정상 탐지한 비율 |
| Invalid 판정성능 | C선 미검출·품질불량 검사를 Invalid로 구분한 성능 |
| 정성판독 일치도 | 기준 판독과 Positive·Negative·Invalid 결과가 일치한 정도 |
| T/C 반복촬영 변동계수 | 동일 Cassette 반복촬영의 반정량 신호 변동 |
| 이미지 QC 실패율 | 촬영결과 중 Retake가 필요한 비율 |
| 재촬영 성공률 | 최초 QC 실패 후 재촬영으로 유효 이미지를 확보한 비율 |

### 3. 검사·AI KPI

| KPI | 정의 |
|---|---|
| 검사이력 완전성 | 시료·키트·이미지·광학값·위험도가 연결된 비율 |
| 자동 재검 수행률 | 재검조건 발생 건 중 실제 재검이 완료된 비율 |
| 재검 해소율 | 재검을 통해 Invalid·Uncertain 상태가 해소된 비율 |
| 위험등급 재현성 | 동일 입력에 대해 같은 Risk Level과 Reason Code가 생성되는 정도 |
| 기준검사 일치도 | 전문기관 기준검사와 시스템 결과가 일치한 정도 |
| 위양성·위음성률 | 공식검사 label 확보 후 계산하는 오류지표 |
| 경보 선행시간 | 시스템 경보와 공식 확인검사·예정검사 사이의 시간차 |
| 시계열 분석 유용성 | 단일 검사 대비 재검·확인검사 우선순위 성능의 변화 |
| Risk Calibration | 위험단계와 실제 공식결과 발생률의 대응정도 |

### 4. 현장운영 KPI

| KPI | 정의 |
|---|---|
| 장비 가동률 | 전체 운영시간 중 정상 사용 가능한 시간 비율 |
| 자동검사 완료율 | 예정검사 중 관리자 개입 없이 완료된 비율 |
| 관리자 개입시간 | 검사·오류복구·소모품 교체에 필요한 시간 |
| 장애복구시간 | 오류발생부터 정상운영 복귀까지의 시간 |
| 소모품 교체주기 | Cartridge·Tip·Cassette 등의 실제 교체빈도 |
| 검사 1회당 소모품비 | 1회 유효검사에 투입되는 소모품 비용 |
| 유지관리 빈도 | 농장·장비당 점검과 수리 발생횟수 |
| 데이터 동기화 성공률 | 오프라인 저장 후 서버에 정상 동기화된 비율 |

### 5. Multi-point·Network KPI

| KPI | 정의 |
|---|---|
| Sampling Point별 데이터 완전성 | 각 지점의 검사·T/C·재검 데이터가 유지된 비율 |
| 지점간 신호차이 | 동일 축사 내 지점별 검사신호와 추세의 차이 |
| Multi-point 추가정보 | 단일지점에서는 확인되지 않은 지점별 이상정보 |
| Network 데이터 완전성 | Farm·Vehicle·Visit 관계를 구성할 수 있는 기록 비율 |
| 후보농장 포함률 | 사후 확인된 연결농장이 우선순위 후보에 포함된 정도 |
| 우선순위 생성시간 | 위험신호 후 관련 농장 후보목록 생성까지의 시간 |
| 전문기관 활용성 | 방역 담당자가 후보정보를 조사에 유용하다고 평가한 정도 |

### 6. 방역·사업효과 KPI

다음 지표는 농장 실증과 공식결과가 축적된 이후 평가한다.

- 경보 후 공식검사 요청까지의 시간
- 공식검사와 이동통제 개시시간
- 농장 간 추가 발생 여부
- 예방적 살처분 대상 규모
- 관리자 업무시간 변화
- 비용회피 잠재액
- 사용자 만족도

이 지표는 실증 전에는 확정적 절감효과나 성과수치로 표현하지 않는다.
